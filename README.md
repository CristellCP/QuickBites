# Quick Bites | Menú digital

Página web estática creada con HTML, CSS y JavaScript.

## Cómo abrir el proyecto
1. Abre la carpeta `QuickBites` en Visual Studio Code.
2. Abre `index.html` en el navegador. También puedes instalar la extensión Live Server y usar "Open with Live Server".
3. Los productos se editan en `js/script.js`, dentro del arreglo `products`.

## Estructura
- `index.html`: estructura de la página.
- `css/styles.css`: estilos y diseño adaptable.
- `js/script.js`: productos, filtros y menú móvil.
- `images/`: logo y fotografías recortadas del menú PDF original.

## Datos que conviene verificar antes de publicar
- El nombre, descripción y precio de cada producto.
- Los nombres de algunas bebidas y salsas, que en el PDF tienen texto pequeño.
- Que el enlace de Instagram corresponda a la cuenta oficial.
- La disponibilidad y precios vigentes.

Los precios se conservaron con el símbolo `$` tal como aparecen en el menú original.
